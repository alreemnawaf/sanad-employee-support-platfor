# Sanad – Employee Support Platform

Sanad is a mobile-first employee support platform designed to provide a secure and accessible environment for workplace support and internal complaint management.

## Overview

Sanad enables employees to submit and track workplace complaints, including anonymous reports, while providing HR personnel with tools to review, manage, and respond to cases.

The platform also incorporates AI-assisted complaint classification and routing to support more efficient case management.

## Key Features

- Secure employee complaint submission
- Anonymous complaint reporting
- Complaint and case tracking
- Leave request management
- HR case management
- Role-based access control
- AI-assisted complaint classification and routing
- Mobile-first user experience

## Technologies

- Flutter
- Firebase
- Python
- AI-based text classification

## Security & Privacy

The system is designed with employee privacy and secure access in mind, particularly for sensitive workplace complaints and anonymous reporting.
